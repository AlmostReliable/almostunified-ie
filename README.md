## **📑 Information**

This is a mod for [Minecraft]-[NeoForge].<br>

It adds [Almost Unified][au] integration to [Immersive Engineering][ie].<br>
Previously, integration was part of the base mod [Almost Unified][au]. With the increasing number of compatibility issues, the authors of
[Immersive Engineering][ie] were contacted to see if they would be interested in direct integration. This was declined.

In order to continue to ensure seamless integration, an add-on was the only option. With the add-on, it is now also possible to convert not
only [Immersive Engineering][ie] recipes, but also the internal priority system used, for example, by ore deposits or Arc Furnace recycling.

While this add-on is installed, the priorities in the [Immersive Engineering][ie] config are only used if the items are not already handled
by [Almost Unified][au].


## **🔧 Manual Installation**

1. Download the latest **mod jar** from the [releases], from [CurseForge] or from [Modrinth].
2. Install Minecraft [NeoForge].
3. Drop the **jar file** into your mods folder.
